# Wireframe Jobsheet 4 — Konsistensi halaman SIMPUS

Jobsheet 4 menyelaraskan halaman beranda, daftar, dan form serta rancangan wireframe. Tidak ada halaman login. Menu seluler pada tahap ini dibuka dengan kontrol checkbox/CSS.

## Pola halaman

```text
+------------------------------------------------------------+
| SIMPUS                                [☰ kontrol navigasi] |
| Beranda | Daftar Buku | Daftar Anggota                     |
+------------------------------------------------------------+
| BERANDA: sambutan + kartu ringkasan statis                  |
| DAFTAR: judul + tombol tambah + tabel data contoh           |
| FORM: label + input + pilihan + tombol simpan/kembali       |
+------------------------------------------------------------+
| Footer SIMPUS — Jobsheet 4                                  |
+------------------------------------------------------------+
```

## Daftar buku dan anggota

```text
Daftar Buku / Daftar Anggota               [+ Tambah]
+------------------------------------------------------------+
| Header kolom sesuai data                                    |
| Isi tabel statis                                            |
| Aksi visual (belum ada backend)                             |
+------------------------------------------------------------+
```

## Navigasi seluler

- Pada lebar kecil, kontrol menu mengubah tampilan navigasi menggunakan CSS.
- Tautan menuju halaman daftar buku dan anggota tetap tersedia.
- `docs/wireframe.md` adalah rancangan, bukan halaman yang ditampilkan aplikasi; infografis juga berfungsi sebagai bahan visual.
