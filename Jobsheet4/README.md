# Jobsheet 4 — Navigasi dan Tampilan Responsif

## Tujuan

Menyempurnakan antarmuka SIMPUS agar navigasi dan konten nyaman digunakan pada layar kecil maupun besar.

## Isi dan fitur

Jobsheet ini memakai halaman HTML beranda, daftar, dan form seperti tahap sebelumnya serta stylesheet responsif tersendiri. Navbar seluler menggunakan kontrol toggle berbasis checkbox dan CSS untuk membuka atau menyembunyikan menu. Halaman login tidak termasuk dalam versi saat ini.

## Konsep yang dipelajari

- Media queries dan breakpoint.
- Menu navigasi yang dapat dibuka pada tampilan mobile.
- Pengaturan jarak, ukuran komponen, dan overflow tabel pada layar sempit.
- Memisahkan perilaku tata letak ke stylesheet.

## Menjalankan dan menguji

Buka `index.html` melalui browser. Uji menu pada layar sempit dengan tombol hamburger, lalu buka daftar buku/anggota dan formulir. Periksa apakah tabel tetap dapat dibaca tanpa menyebabkan seluruh halaman melebar.

## Berkas utama

- `assets/css/style.css`: tema dan aturan responsif.
- `index.html`, `buku/`, dan `anggota/`: halaman antarmuka.

> Konten masih berupa contoh front-end dan belum dipersistenkan ke server.
