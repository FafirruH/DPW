# Wireframe Jobsheet 3 — Bootstrap dan CSS kustom

Rancangan halaman masih SIMPUS statis. Jobsheet 3 menata ulang area menggunakan komponen/grid Bootstrap dan mempertahankan gaya khusus proyek melalui `assets/css/style.css`.

## Beranda

```text
+------------------------------------------------------------+
| SIMPUS                                  [Menu responsif]   |
| Beranda | Daftar Buku | Daftar Anggota                     |
+------------------------------------------------------------+
| Sambutan perpustakaan mini                                  |
+------------------------------------------------------------+
| Ringkasan                                                   |
| +----------------+ +----------------+ +----------------+  |
| | Total Buku     | | Anggota        | | Peminjaman     |  |
| +----------------+ +----------------+ +----------------+  |
+------------------------------------------------------------+
| Footer Jobsheet 3                                           |
+------------------------------------------------------------+
```

## Halaman daftar dan form

```text
Daftar Buku / Daftar Anggota               [+ Tambah]
+------------------------------------------------------------+
| Tabel statis: header kolom | baris contoh | tombol aksi    |
+------------------------------------------------------------+

Tambah Buku / Tambah Anggota
+------------------------------------------------------------+
|                         Form tambah                         |
|                   Label + field input                       |
|                   Label + field input                       |
|                   [Simpan] [Kembali ke daftar]              |
+------------------------------------------------------------+
```

Bootstrap membantu grid, tombol, tabel, dan navigasi responsif; CSS kustom mengatur warna, jarak, dan identitas visual. Aksi edit/hapus masih berupa tampilan, belum mengubah data.
